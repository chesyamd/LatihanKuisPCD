Definisi inti — wajib hafal

Apa itu citra?
Citra adalah sinyal dwimatra yang menyatakan intensitas cahaya pada bidang dua dimensi, secara matematis f(x,y).
Apa itu citra digital?
Representasi citra kontinu yang telah didiskritisasi sehingga dapat direpresentasikan dan diproses komputer, umumnya sebagai matriks pixel.
Apa itu pengolahan citra digital?
Proses komputer untuk melakukan operasi pada citra agar kualitasnya diperbaiki, informasi tertentu ditonjolkan, atau fitur/objek dianalisis.
Apa itu computer vision?
Proses yang mengintegrasikan akuisisi, pemrosesan, klasifikasi/pengenalan, interpretasi, dan penggunaan informasi visual untuk tujuan tertentu.
Apa itu pixel?
Elemen penyusun citra digital yang memiliki posisi serta nilai intensitas atau warna.
Apa itu histogram?
Grafik yang menunjukkan frekuensi kemunculan nilai intensitas pixel pada citra.

1. Pengantar PCD

Intinya: citra diproses → kualitas/informasi diperbaiki → citra dapat dianalisis atau dipahami.

Image Enhancement
Memperbaiki tampilan/menonjolkan ciri: brightness, contrast, sharpening, noise filtering.
Image Restoration
Menghilangkan atau meminimalkan degradasi ketika penyebab degradasi diketahui.
Image Analysis
Mengukur dan mengekstraksi ciri untuk menghasilkan deskripsi.
Image Compression
Membuat representasi citra lebih ringkas untuk penyimpanan/transmisi.
Interpolation
Memperkirakan nilai pixel ketika ukuran/posisi citra diubah.
Pattern Recognition
Mengenali keteraturan/pola untuk mengidentifikasi objek.

Image Processing vs Computer Vision

LevelInput → OutputContoh
LowImage → Imagenoise removal, sharpening
MidImage → Attributessegmentation, object detection/recognition
HighAttributes → Understandingscene understanding, autonomous navigation

Hafalan: image processing terutama memanipulasi citra; computer vision melangkah sampai atribut, pemahaman, dan keputusan.

Tahapan penting

Acquisition → Enhancement/Restoration → Morphological Processing → Segmentation → Representation & Description → Recognition. Ada pula colour image processing dan compression.

2. Pembentukan & Digitalisasi Citra

Citra digital direpresentasikan sebagai matriks M × N. M = baris, N = kolom. Setiap elemen adalah pixel.

f(x,y) = nilai intensitas pada posisi (x,y)

Citra 1200 × 1500 memiliki 1.800.000 pixel.

Sampling vs Quantization

Yang didiskritisasiMakna sederhana
SamplingKoordinat spasial x,yBerapa banyak pixel dan bagaimana susunannya.
QuantizationNilai intensitasBerapa banyak level intensitas yang tersedia.
Kunci: sampling = posisi/pixel; quantization = nilai intensitas/graylevel.

Graylevel

Jumlah level biasanya K = 2m. 1 bit → 2 level; 2 bit → 4; 4 bit → 16; 8 bit → 256 (0–255).

Jenis citra

JenisCiri
Binary1 bit; nilai 0 dan 1.
GrayscaleUmumnya 8 bit; 0–255.
RGBR,G,B; 8 bit per kanal = 24 bit/pixel.

Resolusi & sensor

Resolusi berkaitan dengan detail citra dan jumlah pixel. Sensor CCD dan CMOS digunakan untuk akuisisi citra dan memiliki mekanisme pembacaan sinyal yang berbeda.

3. Format Citra

File citra biasanya mempunyai header; banyak format memiliki signature/magic number untuk identifikasi format.

FormatYang perlu dihafal
PBMPortable Bitmap, citra biner.
PGMPortable Graymap, grayscale.
PPMPortable Pixmap, warna.
BMPUmumnya tidak terkompresi; kualitas terjaga, ukuran besar; punya header dan dapat memakai palet untuk ≤8 bit/pixel.
GIFPalet + LZW; cocok warna terbatas; dapat animated.
JPEGLossy + DCT; file lebih kecil dengan penurunan kualitas visual.
PNGPortable Network Graphics; format terbuka yang banyak dipakai di internet.
TIFFTagged Image File Format; format fleksibel untuk citra.
FITSFlexible Image Transport System; umum pada data/citra astronomi dan ilmiah.
RawTidak mempunyai format spesifik; berisi ukuran dan data bitmap, dapat berupa ASCII untuk grayscale.

Indexed vs Truecolor

Indexed: matriks pixel berisi indeks ke colormap/palet RGB. Truecolor: nilai R,G,B langsung disimpan tanpa palet.

Pada RGB 24-bit: 224 = 16.777.216 kombinasi warna.

Catatan ujian: kalau ditanya “format mana yang lossy dan memakai DCT?” → JPEG. “format palet + LZW?” → GIF. “umumnya tidak dikompresi?” → BMP.

Operasi wajib

Thresholding
Membandingkan pixel dengan ambang T.A<T → 0; A≥T → 1
Negatiff' = 255 − f
Brighteningf' = f + bClipping ke 0–255.
RGB → GrayscaleY = 0.299R + 0.587G + 0.144B

Operasi aritmetika

C=A+BC=A−BC=A×B (pixel bersesuaian)

Penjumlahan beberapa citra yang sama dapat membantu mengurangi noise dengan perataan. Pengurangan citra dapat dipakai untuk mendeteksi perubahan/cacat.

Clipping: pada citra 8-bit, hasil <0 menjadi 0 dan hasil >255 menjadi 255.

5. Histogram Citra

Histogram = distribusi/frekuensi nilai intensitas. Histogram memberi informasi tentang brightness dan contrast, tetapi tidak menunjukkan posisi pixel.

Normalisasi

hᵢ = nᵢ / n

nᵢ = jumlah pixel dengan intensitas i; n = total pixel. hᵢ berada pada 0–1 dan dapat dipandang sebagai peluang pixel memiliki intensitas i.

PolaKecenderungan
Banyak di kiriGelap
Banyak di kananTerang
Rentang sempitKontras rendah
Rentang lebarKontras lebih tinggi
Ingat: histogram RGB dibuat untuk masing-masing kanal R, G, dan B.
